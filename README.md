# Basic Rule-Based Chatbot

## Description
A simple rule-based chatbot developed using Python as part of the CodeAlpha Internship.

## Features
- Responds to greetings
- Answers basic questions
- Handles user input
- Continuous conversation using loops
- Exits gracefully on command

## Technologies Used
- Python
- Functions
- If-Elif-Else
- While Loops
- String Methods

## How to Run

1. Download chatbot.py
2. Open terminal
3. Run:

python chatbot.py
